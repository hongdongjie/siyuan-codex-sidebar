# Codex 侧边栏

在思源侧栏与 Codex 对话，支持模型与思考强度选择、上下文用量、历史记录、消息编辑和自定义前置提示词。

## 使用条件

- Windows 桌面端，思源 3.8.6+。
- 本机已安装并登录 Codex，无需保持 Codex 窗口打开。
- 访问思源笔记需配置思源 MCP。

## 使用

选择模型后即可对话。Enter 发送，Shift+Enter 换行。

模型与强度切换从下一条消息生效；前置提示词对新对话生效。悬停模型左侧圆环可查看上下文用量。

未登录时，请到本机 Codex 登录；找不到程序时，可在连接设置中指定 `codex.exe` 路径。

## 数据与权限

聊天记录和设置由思源保存。消息及通过 MCP 读取的内容会发送给所配置的模型服务；需要审批的操作在侧栏确认。

第三方社区插件，与 OpenAI、思源官方无隶属关系。MIT 许可证。
