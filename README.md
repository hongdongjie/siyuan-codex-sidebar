# Codex 侧边栏

在思源笔记侧栏与 Codex 对话，支持模型与思考强度选择、上下文用量、历史对话、消息编辑和自定义前置提示词。

**从思源集市安装即可，无需手动下载或解压。** 插件复用本机 Codex 登录状态，无需重复登录，也无需保持 Codex 桌面窗口打开。

## 使用条件

- 思源笔记 3.8.6 或以上的 Windows 桌面端，插件界面为简体中文。
- 本机已安装并登录 Codex，且能正常使用 Codex 桌面应用或 CLI。插件不会代为安装 Codex。
- 如需通过 Codex 访问思源笔记，需先配置可用的思源 MCP；未配置时仍可进行普通对话。

## 从集市安装

1. 打开思源「设置 → 集市 → 插件」，搜索 **Codex 侧边栏**并安装。
2. 在「已下载 → 插件」中确认插件已启用。
3. 点击右侧栏的 Codex 图标，在输入框下方选择模型，即可开始对话。

插件启用后自动连接本机 Codex。后续版本可在思源集市中更新，无需重新解压安装。

## 功能与操作

| 功能 | 操作 |
| --- | --- |
| 发送消息 | Enter 发送，Shift+Enter 换行；生成期间可停止 |
| 新建与切换对话 | 顶部加号新建对话，时钟打开历史记录；空白对话不进入历史记录 |
| 模型与思考强度 | 点击输入框下方的模型入口，选择模型或调整滑杆；自动保存，从下一条消息生效 |
| 上下文用量 | 悬停或聚焦模型左侧圆环，查看已用、剩余比例及 Token 数量 |
| 编辑消息 | 点击最近一条用户消息旁的铅笔，修改后重新发送 |
| 前置提示词 | 在设置中保存，新建对话后生效；已有对话保留原提示词 |
| 收起侧栏 | 点击顶部减号 |

模型和强度由用户手动选择，不同步 Codex 桌面聊天的选择。可用档位取决于模型，新对话沿用最近选择。上下文用量来自 Codex 上报，尚未收到数据时显示暂无数据。

切换对话时保留草稿。编辑并重新发送消息会基于此前上下文创建分支，替换该消息及其旧回答；已经执行的操作不会撤销。

## 常见问题

**需要一直打开 Codex 桌面窗口吗？**

不需要。插件会在后台启动本机 Codex，并复用已有登录状态。

**提示未登录怎么办？**

在本机 Codex 完成登录，再回到插件发送消息。插件不提供独立网页登录入口。

**找不到 Codex 怎么办？**

先确认本机已安装 Codex。插件优先检测 Codex 桌面应用携带的程序；检测失败时，可在「设置 → 连接设置」中填写 `codex.exe` 的完整路径。如果提示配套文件缺失，请更新或修复 Codex 安装。

**可以聊天，但无法访问思源笔记？**

请检查同一 Codex 配置目录中的思源 MCP 是否已配置并正常连接。插件不会自动配置 MCP，也不会直接扫描笔记。

**连接断开怎么办？**

插件会自动重试；仍未恢复时，发送消息会再次尝试连接。中断的消息不会自动重发。

**升级后提示选择模型？**

新版仅保留手动选择。旧对话如果使用过“跟随 Codex”，需在输入框下方选择一次模型。

## 数据与权限

聊天记录、前置提示词和插件设置通过思源保存；是否跨设备同步取决于思源配置。登录凭据由 Codex 管理，插件不另行保存。

默认读取用户主目录下的 `.codex` 配置，连接设置可以指定其他目录。切换目录后，旧会话可能无法恢复，可新建对话。

消息和通过 MCP 读取的内容会交给所配置的 Codex 模型服务处理。插件使用只读文件沙箱；需要审批的命令、文件与 MCP 操作会在侧栏请求确认。复杂 MCP 表单暂不支持，只能拒绝。

本插件不导入 Codex 桌面聊天列表，也不保证提供桌面应用的全部专属工具。

## 手动安装（备用）

仅在无法使用集市时采用：从 [GitHub Releases](https://github.com/hongdongjie/siyuan-codex-sidebar/releases/latest) 下载 `package.zip`，解压到 `工作空间/data/plugins/siyuan-codex-sidebar/`。目录下应直接包含 `plugin.json`、`index.js` 和 `index.css`，然后在思源中启用插件。

## 开发与验证

- `npm run build`：生成 `dist/siyuan-codex-sidebar`，构建无需安装 npm 依赖。
- `npm test`：执行协议、连接与状态回归测试。
- `node scripts/ui-test.cjs`：执行界面测试，需要 Playwright、Chrome 和思源资源；可通过脚本中的 `CODEX_TEST_*` 环境变量指定路径。
- `node scripts/smoke.cjs`：检查真实 App Server 登录状态与 MCP 发现，不读取笔记正文。

协议基于 Codex CLI 0.159.2 的 App Server schema，兼容性可能随 Codex 版本变化。
