# Codex 侧边栏 · 思源桌面插件

在思源笔记右侧连续与 Codex 对话，沿用本机 Codex 登录、模型配置和思源 MCP。支持保存前置提示词、聊天记录、新建对话、停止生成和基本操作审批。不提供回答插入笔记或附件按钮。

支持思源 3.8.6 及以上的 Windows 桌面端，界面为简体中文。需要已安装并登录的 Codex CLI（或包含 codex.exe 的 Codex 桌面应用）。本插件是第三方社区项目，与 OpenAI、思源官方无隶属关系。

## 安装

1. 将发布包解压为 `工作空间/data/plugins/siyuan-codex-sidebar/`，该目录下应直接包含 `plugin.json`、`index.js`、`index.css` 和本文件。
2. 在思源「设置 → 集市 → 已下载 → 插件」启用 **Codex 侧边栏**。如未发现，重新打开思源。
3. 插件启用后自动连接本机 Codex；点击右侧栏的 Codex 图标即可使用。

需要 Windows 桌面端及 Codex CLI。优先自动检测 Codex 桌面应用携带的 `codex.exe`，也可在设置里填完整路径。无需保持 Codex 桌面窗口打开。

## 使用

- 直接说“查找我的某某笔记并解释其中的内容”，Codex 会使用已有思源 MCP；无需选择或粘贴整篇笔记。
- 点「设置」打开窗口中央的弹窗，填写前置提示词并保存，然后点「新对话」启用它。旧对话继续使用创建时的提示词。可点击关闭按钮、遮罩或按 Esc 关闭弹窗。
- 设置中的「模型」下拉列表从 Codex 自动加载，支持刷新；选择后保存并新建对话生效，旧对话保留原模型。「跟随 Codex 默认配置」使用默认模型。
- Enter 发送，Shift+Enter 换行；生成中可以停止。顶部加号新建对话，时钟图标展开历史记录，齿轮打开设置。历史记录中勾选当前对话，切换时保留各自草稿；支持方向键选择、Enter 打开、Esc 或点击外部关闭。
- 你的消息以靠右的绿色气泡显示。最近一条消息右下方可点铅笔，在原消息位置直接编辑，右下角提供「取消」与「发送」；底部输入框的草稿保持不变。Enter 发送，Shift+Enter 换行，Esc 取消。生成期间不可编辑。重新发送从该消息之前的上下文创建分支，当前界面替换旧消息及其回答；已执行的笔记操作不会撤销。
- 默认读取用户主目录 `.codex`。连接设置可指定其他配置目录或模型；不会修改原 Codex 配置。
- 已登录时直接使用；若未登录，点「登录 ChatGPT」完成官方浏览器授权。
- 打开思源时自动连接，意外断线后按 5、15、30、60、60 秒间隔最多重试五次；仍失败时，发送消息会重新连接。左下角不再提供「连接 / 检查连接」按钮。自动连接仅检查登录与 MCP 状态，不发送消息或读取笔记，也不会自动重发中断的请求。关闭思源时正常结束连接，下次打开自动恢复。

## MCP 与权限

思源 MCP 来自 Codex 的 `config.toml`，需已配置并能连接。连接检查会报告是否发现思源工具，工具执行记录默认隐藏。未配置思源 MCP 时仍可聊天，但不能通过它读取笔记。插件本身不扫描笔记、不直接写入笔记；MCP 可以执行的操作仍取决于 MCP 服务及你给 Codex 的指令。

使用 `read-only` 文件沙箱与 `on-request` 审批策略。命令、文件和 MCP 工具调用审批在侧栏内确认，额外权限扩展默认不授予。本版支持 Codex 问答请求；复杂 MCP 表单仅支持拒绝。不承诺复用 Codex 桌面专属工具，也不导入桌面应用聊天列表。

## 数据

前置提示词与本插件对话保存在插件的 `sidebar.json`，通过思源官方 `saveData` 保存；是否跨设备同步由思源配置决定。Codex 原始会话保存在对应 Codex 配置目录。登录凭据由 Codex 自己管理，不复制到插件存储。

提示词、消息和通过 MCP 读取的内容会由 Codex 发送给所配置的模型服务。切换配置目录后，旧会话可能无法恢复，可新建对话。

## 开发与验证

`npm run build` 生成 `dist/siyuan-codex-sidebar`；`npm test` 执行协议和状态测试。项目不依赖 npm 安装即可构建。

`node scripts/smoke.cjs` 验证真实 App Server 登录状态与 MCP 发现（不读取笔记正文）。`node scripts/smoke.cjs --chat` 额外执行两轮短消息，验证前置提示词和连续上下文。`--mcp` 仅批准思源版本查询，验证真实 MCP 调用链路。

协议以本机 Codex CLI 0.159.2 导出的 schema 为依据。App Server 随 Codex 版本演进，升级后如遇连接问题可运行 smoke 检查。

官方参考：[App Server](https://learn.chatgpt.com/docs/app-server)、[思源插件](https://github.com/siyuan-note/plugin-sample)。
